# File Tab Cleaner

ファイル編集画面のタブを固定し、固定していないタブをまとめて閉じるプラグインです。

## 使い方

1. このプラグインをインストールします
2. ファイル編集画面のタブの列の一番左に、全消去ボタン（⊗）が追加されます
3. ボタンを押すと、固定していないタブがすべて閉じます

ファイル本体は削除されません。未保存の変更は閉じる前に保存します。右に開いた分割画面でも同じように使え、固定したタブがなければその画面のタブをすべて閉じて分割を終了します。

## タブの固定

- タブを0.5秒ほど長押しすると固定し、もう一度長押しすると解除します
- タブを右クリックして「タブを固定」/「固定を解除」でも切り替えられます
- 固定したタブは名前の左にピンの印が付き、タブの列の左側にまとまります
- 固定したタブも × で閉じられます。閉じると固定も外れます
