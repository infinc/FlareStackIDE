# CSV Viewer

CSV と TSV をファイル編集画面で表として表示し、編集するプラグインです。

## 使い方

セルをダブルクリックすると編集でき、確定するとすぐファイルに保存します。上のバーのボタンで行と列を追加・削除できます。行を追加すると選択中の行の下に入ります。列の削除は最後に押したセルか列見出しの列、押していなければ最後の列が対象です。
