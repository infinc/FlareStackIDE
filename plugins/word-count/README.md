# Word Count

今のファイルや選択範囲の文字数（改行を除く）・空白を除いた文字数・語数・行数・バイト数を数えて、右下の通知に出します。

## 使い方

コマンドパレット（⌘⇧P）で次を選びます。

- 「文字数: 今のファイルを数える」
- 「文字数: 選択範囲を数える」

## しくみ

このプラグインは、本体の型に直接つながらない「C の API」（`flarestack_host_symbol` で関数を名前で引く方式）で動きます。そのため、本体を更新しても作り直す必要がありません（`plugin.json` の `"abi": "c"` と `"hostAPI"`）。

数える処理は、本体とは別のプロセス（XPC サービス `FlareStackPluginHost`）で動きます。処理が異常終了しても本体は落ちず、2回続くとこのプラグインを止めます。
