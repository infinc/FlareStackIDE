# Git Actions

コマンドを打たずに Git を操作するプラグインです。左のアイコン列のボタンで専用のフィードを開きます。

上の帯にブランチと上流との差（↑ push 待ち / ↓ pull 待ちのコミット数）、操作ボタンが並びます。左はステージ済みと変更のファイル一覧（種類の色付きバッジ・ファイル名・フォルダ）、右はコミットのカードです。

## できること

| 操作 | 内容 |
|---|---|
| ステージ / 解除 | ファイルごとの ＋ / −、見出しの ＋ / − ですべて |
| 変更の破棄 | ↩︎（確認あり。元に戻せません。新規ファイルは削除します） |
| コミット | メッセージを入力して「コミット（件数）」か ⌘↩。開いているファイルは先に保存します。カードの下に前回のコミットを表示 |
| ブランチ | 左上のメニューで切り替え、「新しいブランチ…」で作成 |
| Fetch / Pull / Push | Pull は fast-forward のみ。上流がないブランチの Push は `origin` に設定します。pull / push 待ちのコミットがあるとボタンに件数を表示 |
| Stash / Stash Pop | トレイのアイコン。新規ファイルも含めて退避 / 戻す |
| Stash ▾ | stash ごとに「適用（残す）」「Pop」「削除…」 |
| タグ ▾ | 「タグを作成…」（メッセージを入れると注釈付き）、「全てのタグを push」、タグごとに push / 削除（origin からも削除できる） |
| Rebase ▾ | 今のブランチを、選んだローカル / リモートのブランチの上に rebase（確認あり） |
| 途中の操作 | マージや rebase の途中は上に帯が出て、「続ける」「スキップ」「中止」（rebase）、「マージを完了」「マージを中止」を押せます |

ファイル名を押すと、そのファイルを開きます。

ブランチの切り替え・Pull・Stash・変更の破棄の前にも、開いているファイルを保存します。一覧は入力が止まって1.5秒後にも更新します。

Fetch / Pull / Push / Stash はコマンドパレット（⌘⇧P）の「Git: …」からも実行できます。競合の解決は Merge Resolver プラグインを使ってください。

force push はありません。パスワードの入力が必要な push や pull は失敗して通知が出るので、ターミナルで実行してください。

## 更新履歴

### v1.5

- 画面の刷新（ブランチと上流との差の表示、アイコン付きの操作ボタン、色付きバッジのファイル一覧、コミットのカード）
- pull / push 待ちのコミット数をボタンに表示
- ⌘↩ でのコミット、カードの下に前回のコミットを表示
- Git リポジトリではないときと、変更がないときの案内を表示

### v1.4

- インストール時に確認する権限（外部コマンドの実行）の追加
- ほかのプラグインとの連携に使う通知名を本体の共通定義に統一

### v1.2

- コマンドパレットの「Git: Fetch / Pull / Push / Stash」を追加
- プラグイン API 1（apiVersion 1）への対応
- 配布ファイルのハッシュと署名による改ざんの確認に対応

- コミットしたことを Git Blame などに知らせ、表示をすぐに更新
- 特殊な文字を含むファイル名のステージ・解除・破棄に対応、名前の変更の表示を修正
