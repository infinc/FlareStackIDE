# Git Actions

コマンドを打たずに Git を操作するプラグインです。左のアイコン列のボタンで専用のフィードを開きます。

## できること

| 操作 | 内容 |
|---|---|
| ステージ / 解除 | ファイルごとの ＋ / −、見出しの ＋ / − ですべて |
| 変更の破棄 | ↩︎（確認あり。元に戻せません。新規ファイルは削除します） |
| コミット | メッセージを入力して「コミット」。開いているファイルは先に保存します |
| ブランチ | 左上のメニューで切り替え、「新しいブランチ…」で作成 |
| Fetch / Pull / Push | Pull は fast-forward のみ。上流がないブランチの Push は `origin` に設定します |
| Stash / Stash Pop | 新規ファイルも含めて退避 / 戻す |
| Stash 一覧 ▾ | stash ごとに「適用（残す）」「Pop」「削除…」 |
| タグ ▾ | 「タグを作成…」（メッセージを入れると注釈付き）、「全てのタグを push」、タグごとに push / 削除（origin からも削除できる） |
| Rebase ▾ | 今のブランチを、選んだローカル / リモートのブランチの上に rebase（確認あり） |
| 途中の操作 | マージや rebase の途中は上に帯が出て、「続ける」「スキップ」「中止」（rebase）、「マージを完了」「マージを中止」を押せます |

ファイル名を押すと、そのファイルを開きます。

ブランチの切り替え・Pull・Stash・変更の破棄の前にも、開いているファイルを保存します。一覧は入力が止まって1.5秒後にも更新します。

Fetch / Pull / Push / Stash はコマンドパレット（⌘⇧P）の「Git: …」からも実行できます。競合の解決は Merge Resolver プラグインを使ってください。

force push はありません。パスワードの入力が必要な push や pull は失敗して通知が出るので、ターミナルで実行してください。
