# Web Feed

編集画面の下のフィードで、Google などの Web ページを見られるプラグインです。

## 使い方

1. このプラグインをインストールします
2. 左のアイコン列のターミナルボタンの上に、検索ボタン（🔍）が追加されます
3. 検索ボタンを押すと、下のフィードに Google が表示されます

ターミナル・Git などのフィードとは同時に表示されません。もう一度押すか、右上の － で閉じます。

## タブ

- ＋ で新しいタブ（Google）を開きます
- タブはドラッグで並べ替え、× で閉じられます
- アドレス欄に URL を入れるとそのページを、言葉を入れると Google 検索を開きます。`localhost:3000` や `127.0.0.1:8000` は http で開きます
- ‹ › で戻る・進む、↻ で再読み込み、🏠 で Google、コンパスのボタンで普段のブラウザで開きます

ファイルのアップロードに対応しています。`http://` のページも開けます。ページの中のリンクが別のアプリを開くのは、リンクを押したときだけです（`file:` のリンクは開きません）。

フィードを閉じても、アプリを終了しても、タブは残ります。メモリが足りなくなったときは、表示していないタブのページを一度閉じ、選んだときに読み込み直します。
