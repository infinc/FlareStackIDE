# Scratch Pad

保存しない一時的なメモ用紙を開くプラグインです。

## 使い方

インストールすると、左の大タブにメモのボタンが追加されます。押すと左側にメモのフィードが開き、文字を自由に書いたり消したりできます。

- 行数や色付けはなく、ただの文字を書く場所です
- ファイルには保存しません。フィードを閉じても、ウィンドウを開いている間は内容が残ります
- ウィンドウを閉じるか FlareStackIDE を終了すると内容は消えます
- フィードの右上のごみ箱ボタンでメモを全て消せます

ボタンは他の大タブと同じく ⌘+ドラッグで並べ替えられます。下のグループに移すと、メモは下側に開きます。
