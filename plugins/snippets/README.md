# Snippets

トリガーの単語を入力して Tab を押すと、定型文に展開するプラグインです。

## 使い方

1. `for` などのトリガーを入力します
2. Tab を押すと定型文に展開し、最初の入力箇所を選択します
3. Tab で次の入力箇所へ、⇧Tab で前の入力箇所へ移動します。esc で終わります

Python・JavaScript・TypeScript・Swift・Go・Rust・C / C++・Java・HTML・シェル・Markdown の定型文が入っています。補完候補の表示中でも、トリガーと完全に一致したら展開を優先します。

## 自分のスニペット

歯車メニュー →プラグイン → Snippets の「設定」で追加できます。同じトリガーなら、自分のスニペットを優先します。

| 書き方 | 内容 |
|---|---|
| `$1` `$2` | Tab で移動する場所 |
| `${1:初期値}` | 初期値を選択した状態で移動 |
| `$0` | 最後にカーソルを置く場所 |
| `\n` / `\t` | 改行 / タブ（設定の入力欄） |
