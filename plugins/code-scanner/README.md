# Code Scanner

主要な言語のエラーと警告を、入力しながらリアルタイムで表示するプラグインです。

## 使い方

1. このプラグインをインストールします
2. ファイルを開くと、編集画面の右上に赤い ! (エラー数) と黄色い ⚠ (警告数) が表示されます
3. 数字を押すと、下のフィードに問題の一覧（内容・コード・ファイル名・行）が表示されます
4. 一覧の行を押すと、そのコードの位置に移動します

コード内のエラーは赤い文字と赤い波線、警告は黄色い波線で表示されます。波線の上にマウスを重ねると内容が表示されます。

右に開いた分割画面のファイルも検査し、分割画面の右上にも数を表示します。分割画面の問題も同じ問題フィードに並びます。右上の数にカーソルを合わせると、背景が少し明るくなります。

## エラーと警告の基準

- **エラー（赤）**: そのままでは動かない、または壊れて表示されるもの
- **警告（黄）**: 動くが、間違いの可能性が高いもの

## 検査する内容

| 対象 | エラー | 警告 |
|---|---|---|
| すべてのファイル | マージの競合が残っている | |
| Markdown | コードブロックが閉じられていない | 番号付きリストの番号の重複・飛び（全部 `1.` のリストは対象外）、空のリスト項目、見出しのレベルの飛び、`#` の後の空白がない、空の見出し、表の列の数の不一致、空のリンク、リンク先のファイルが見つからない |
| HTML | | タグの閉じ忘れ、開始タグのない閉じタグ |
| XML / SVG / plist | タグの対応の誤り | |
| JSON / JSONC（`tsconfig.json`・`.vscode` の中などはコメントと末尾のカンマを許可。JSON5 は対象外） | 構文エラー | キーの重複 |
| YAML | インデントのタブ | キーの重複 |
| TOML | キー・テーブルの重複、値がない、形式の誤り | |
| TypeScript / Java / Kotlin / Rust / C# / Dart / CSS / SCSS / Less | カッコの対応の誤り | |
| 上記のプログラミング言語と下の表の言語 | 下の表のツールが出すエラー | ツールが出す警告、コード中の全角スペース、Python のタブとスペースの混在 |

## 外部ツールを使う言語

| 言語 | 使うツール |
|---|---|
| Python | python3（構文エラー、SyntaxWarning、未使用の import） |
| JavaScript | node --check |
| Swift | swiftc -parse |
| C / C++ / Objective-C | clang -fsyntax-only |
| Go | gofmt -e |
| Ruby | ruby -wc |
| Shell (bash / zsh) | bash -n / zsh -n |
| PHP | php -l |
| Perl | perl -wc |
| Lua | luac -p |

ツールがインストールされていない言語は、ツールによる検査だけを行いません。

## LSP Client と一緒に使うとき

LSP Client プラグインが言語サーバー（Python なら Pyright など）を動かしているファイルでは、次のように動きます。

- 言語サーバーの診断も、波線・右上の数・問題フィードにまとめて表示します（問題フィードの内容の末尾に出元が付きます）
- 外部ツールによる検査（Python の構文チェック）は止め、同じエラーが二重に出ないようにします。全角スペースやマージ競合の印など、このプラグインだけが見つけるものは引き続き表示します
- ホバーのポップアップは LSP Client が出します（診断と型の情報を1つにまとめます）

## 検査のタイミング

文字を打ち終わって1.5秒後に検査します。エラーや警告の文字列にマウスカーソルを1.5秒ほど当てると、下に概要が出ます。
