# Debugger

Debug Adapter Protocol（DAP）でデバッガとつなぎ、ブレークポイントで止めて、呼び出し履歴・変数・式の評価を確かめます。

## 使い方

1. 行番号を ⌥ を押しながらクリックすると、ブレークポイント（赤い丸）を付け外しできます（⌥ なしのクリックはこれまでどおりブックマーク）
2. 上のバーの ▶ を押すと、今のファイルをデバッグします
3. 止まった行は黄色になり、下のフィード「デバッグ」に呼び出し履歴・変数・デバッグコンソールが出ます
4. 上のバーのボタンで、続行・ステップオーバー・ステップイン・ステップアウト・停止を行います。コマンドパレットの「デバッグ:」からも使えます

デバッグコンソールの入力欄に式を書いて Enter を押すと、選んでいるフレームで評価します。

## 対応している言語

| 種類 | デバッガ | 準備 |
|---|---|---|
| Python（.py） | debugpy | `python3 -m pip install debugpy` |
| Swift / C / C++ / Objective-C / Rust / Go など | lldb-dap（Xcode に同梱） | デバッグ情報付きでビルドした実行ファイル（`swiftc -g` など）。開始のときに選び、プロジェクトごとに覚えます |

Python のコマンドと lldb-dap の場所は、プラグインの設定で変えられます。

## 制限

- 起動構成は「今のファイル」だけです（Runner の起動構成との連携は今後の予定）
- 編集で行がずれても、ブレークポイントの行番号は自動では動きません
