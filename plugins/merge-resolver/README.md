# Merge Resolver

マージや rebase で起きた競合（`<<<<<<<` 〜 `>>>>>>>`）を、ボタンで解決するプラグインです。

## できること

| 操作 | 内容 |
|---|---|
| 色分け | 自分の変更を緑、相手の変更を青、印の行を灰色で表示します（diff3 形式の共通部分も灰色） |
| ボタンで解決 | 各競合の `<<<<<<<` の行の右に「自分の変更」「相手の変更」「両方」を表示します。押すとその内容に置き換わります（⌘Z で元に戻せます） |
| 移動 | ⌥⌘] で次の競合、⌥⌘[ で前の競合へ |
| 一覧 | 左のアイコン列の「マージ競合」で、競合しているファイルの一覧を開きます。押すとそのファイルの最初の競合へ移動します |
| ステージ | ファイルの競合がなくなると通知が出ます。「保存してステージ」で `git add` します |

コマンドパレット（⌘⇧P）からも「競合: …」で同じ操作ができます。

マージや rebase の続行・中止は Git Actions プラグインのフィード上部に出る帯から行えます。

## 設定

| 項目 | 内容 |
|---|---|
| 自分の変更の背景色 | 既定は緑 |
| 相手の変更の背景色 | 既定は青 |
