# Outline

開いているファイルのクラス・関数・見出しを一覧にするフィードです。

## 使い方

- アイコン列の「アウトライン」を押すとフィードが開きます。フィードは他のフィードと同じようにドラッグで左右や上下へ移せます
- 項目を押すと、その場所へ移動します。カーソルを動かすと、今いる項目が選ばれます
- 上の欄に文字を入れると、名前で絞り込めます
- 入力の1秒後に一覧を更新します

## 一覧の取得方法

- LSP Client が動いているファイルでは、言語サーバーのシンボル一覧（documentSymbol）を使います
- それ以外のファイルでは、`class` `struct` `func` `def` `function` などの行と字下げから一覧を作ります。Markdown では見出しを使います
