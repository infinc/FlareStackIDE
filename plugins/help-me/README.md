# Help Me

編集を巻き戻すプラグインです。

## 使い方

上のバーに巻き戻しボタンとやり直しボタンが追加されます。巻き戻しで編集を戻し、やり直しで戻す前の状態にします。ファイルを切り替えると履歴はリセットされます。
