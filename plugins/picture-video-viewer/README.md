# Picture/Video Viewer

写真と動画をファイル編集画面で表示するプラグインです。表示のみで、編集はできません。

## 対応形式

| 種類 | 拡張子 |
|---|---|
| 写真 | jpg, jpeg, png, gif, svg, webp, bmp, tif, tiff, heic, ico |
| 動画 | mp4, m4v, mov, avi |

画面の上にファイルのサイズと解像度を表示します。写真はピンチで拡大できます。

avi は macOS が対応しているコーデックのときだけ再生できます。再生できないファイルはその旨を表示します。

svg も写真として表示します。コードを編集するときは、このプラグインを削除してください。
