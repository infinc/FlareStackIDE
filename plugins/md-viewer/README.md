# MD Viewer

Markdown（`.md` / `.markdown`）ファイルを編集しながら、整形されたプレビューをリアルタイムで確認できるプラグインです。

## 使い方

1. このプラグインをインストールします
2. Markdown ファイルを開きます
3. ファイルタブの下に表示されるバーの3つのボタンで表示を切り替えます（マウスを重ねると名前が表示されます）

右クリック →「右に開く」で右の分割画面に開いた Markdown ファイルにも、同じボタンが表示されます。

## 表示モード

- **コード** — コードだけを表示します（編集できます）
- **コード＋プレビュー** — 左にコード、右にプレビューを並べます
- **プレビュー** — プレビューだけを表示します（編集はできません）

## 対応している記法

- 見出し、段落、引用
- 箇条書き、番号付きリスト、チェックボックス
- **太字**、*斜体*、~~取り消し線~~、`インラインコード`、リンク
- コードブロック、水平線
- 表（`| 見出し | 見出し |` と `|---|:---:|` の区切り行。`:` で左・中央・右寄せ）
- 画像（`![説明](画像のパス)` と `<img src="…">`。パスは Markdown ファイルからの相対パス・絶対パス・URL）

## 設定

歯車メニューの「プラグイン」から MD Viewer の「設定」を押すと、ファイルタブの下に出る切替ボタンのタブを変えられます。

- **タブの背景色** — タブの色。「初期値」で元の色に戻ります
- **透明（ボタンだけを表示）** — タブを消し、切替ボタンだけを編集画面の上に浮かべて表示します
- **透明表示のとき最小化する** — オンにすると、マウスを重ねていない間は今選んでいる表示のボタンだけを表示します（例: コードだけを表示中ならコードのボタンだけ）。マウスを重ねると3つのボタンが表示されます
- **透明表示のボタンの位置** — 右下・右上・左下・左上から選べます。右上にしたときは Code Scanner の問題数の表示と重ならないよう、その下に表示します
