# Interpolate Code

コードを書くときの決まった入力を自動で補います。変数名や日本語・英語の単語は補完しません（変数の補完は Interpolate Variable プラグイン）。

## カッコと引用符

| 入力 | 結果 |
|---|---|
| `(` | `()` を入れ、カーソルを中に置く |
| `[` | `[]` |
| `{` | `{}` |
| `"` | `""` |
| `` ` `` | ``` `` ``` |

- 閉じカッコ・閉じ引用符がカーソルの直後にあるときに同じ文字を打つと、文字を増やさずに後ろへ進みます
- 空のペア（`()` など）の間で ⌫ を押すと、両方を消します
- 文字を選んだ状態でカッコ・引用符を打つと、選んだ文字を囲みます
- 引用符は、直前が英数字のとき（`it"s` など）は補完しません

## 改行

- **Markdown** — `- ` `* ` `+ ` の箇条書き、`1. ` の番号付きリスト（次の番号）、`- [ ] ` のチェックボックス、`> ` の引用を次の行に続けます。中身が空の行で改行するとリストを終わります
- **Python** — `:` で終わる行の次の行を、スペース4つ深くします
- **カッコの中** — `{` `[` `(` の直後で改行すると、中身の行を1段深くし、閉じカッコを次の行に置きます
- それ以外は前の行のインデントを引き継ぎます
