# Sticky Scroll

スクロール中も、今いる関数やクラスの行を上端に固定するプラグインです。

## 使い方

関数やクラスから離れると固定は外れます。固定された行を押すとその行へ移動します。範囲はインデントで判定し、固定は最大5行です。
