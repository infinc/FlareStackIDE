# Lines

ファイル編集画面の左側に行数を表示するプラグインです。新しいファイルを作ったり別のファイルを開いたりしても、行数の列はそのまま表示されます。

## 設定

歯車メニューの「プラグイン」から Lines の「設定」を押すと、次の項目を変えられます。設定画面の下のプレビューに、変更がすぐ反映されます。

- **行数の文字色**
- **背景色** — 行数を表示する列の背景色
- **列の幅** — スライダーで 24〜120 の間で指定します。「初期値」を押すと「自動」（4桁分以上で、行数の桁に合わせた幅）に戻ります
- **行間** — スライダーで 0〜20 の間で行と行の間隔を指定します。編集画面の行間がこの値になります。「初期値」を押すと「自動」（設定画面の「行間」に従う）に戻ります

色の「初期値」を押すと、エディタの配色に合わせた色に戻ります。
