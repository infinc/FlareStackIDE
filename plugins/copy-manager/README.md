# Copy Manager

コピーした文字を履歴として保存し、あとから選んでもう一度コピーできるプラグインです。

## 使い方

1. このプラグインをインストールします
2. ファイル編集画面の上のバーの右側、保存マークの左にクリップのボタン（📎）が追加されます
3. コピーした文字は自動で履歴に保存されます（最大50件。同じ文字は一番上にまとまります）
4. クリップのボタンを左クリックすると、履歴がプルダウンで表示されます
5. 履歴を左クリックすると、その文字がコピーされます

## 右クリックメニュー

クリップのボタンを右クリックすると、次のメニューが表示されます。

- **履歴を全て削除** — 保存した履歴をすべて消します
- **昇順（A-Z）** — 履歴を A から Z の順に並べます
- **降順（Z-A）** — 履歴を Z から A の順に並べます

チェックの付いた並び順をもう一度選ぶと、新しくコピーした順に戻ります。
