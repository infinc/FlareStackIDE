# Indent Guides

インデントの深さごとに縦の線を引くプラグインです。

## 使い方

インストールすると、編集画面と右の分割画面のインデントに薄い線を引きます。カーソルのあるブロックの線は少し濃く表示します。空行は前後の行の浅い方に合わせます。

## 設定

- **インデントの幅**: 「自動」はファイルのインデントから 2・4・8 のどれかを選びます。タブで字下げしたファイルはタブの幅を使います。
- **線の色** / **強調した線の色**: 未設定なら文字色を薄くした色です。
- **カーソルのあるブロックの線を強調**: オフにすると全ての線を同じ色で引きます。
