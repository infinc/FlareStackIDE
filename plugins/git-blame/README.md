# Git Blame

カーソルのある行を最後に変更した人と時期を、行末に薄い文字で表示するプラグインです。

## 表示

```
print("hello")      山田, 3日前 • ログの出力を追加
```

コミットされていない行は「未コミット」と表示します。編集中の内容で調べるので、保存前でも行がずれません。入力中は隠れ、入力が止まって1秒後に表示を更新します。

範囲を選択しているときは表示しません。Git で管理していないファイル、40万文字を超えるファイル、設定で Git 連携をオフにしているときも表示しません。

## 設定

歯車メニュー →プラグイン → Git Blame の「設定」で文字色を変えられます。
