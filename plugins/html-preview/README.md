# HTML Preview

HTML ファイル（`.html` / `.htm` / `.xhtml`）を開くと、コードの横にページを表示するプラグインです。

## 使い方

- 右下の3つのボタンで「コード」「コード＋プレビュー」「プレビュー」を切り替えます（MD Viewer と同じ操作）
- 入力の0.3秒後に表示を更新し、スクロール位置はそのまま残します
- `<link href="style.css">` や `<script src="app.js">` のような相対パスは、HTML と同じフォルダを基準に読み込みます
- 同じフォルダにある `.css` / `.js` は、HTML に書いていなくても自動で読み込みます（設定で止められます）
- CSS / JS を別のタブで保存すると、1秒以内にプレビューへ反映します

## 設定

- 同じフォルダの CSS / JS を自動で読み込む（初期値: オン）
- 外部（http / https）の読み込みを許可（初期値: オフ）
- タブの背景色、透明（ボタンだけを表示）、透明表示のとき最小化する、ボタンの位置（右下 / 右上 / 左下 / 左上）

## 安全のための制限

- ページの JavaScript は動きますが、初期状態では外部への通信（http / https / ws / file など）を全て遮断します
- 読み込めるローカルのファイルは HTML のあるプロジェクト（`.git` か `package.json` のあるフォルダ）の中だけです
- ページ内のリンクを押してもプレビューは移動せず、ブラウザや Finder で開きます
