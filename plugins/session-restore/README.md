# Session Restore

終了時に開いていたタブとカーソル位置を、次にプロジェクトを開いたときに復元するプラグインです。

## 使い方

インストールするだけで動きます。プロジェクトを閉じたり FlareStackIDE を終了したりしたときの状態を、プロジェクトごとに記録します。

復元する内容は次のとおりです。

- 左のファイル編集画面のタブの並びと、選択していたタブ
- 右に開いた分割画面のタブと、選択していたタブ
- ファイルごとのカーソル位置（選択範囲）とスクロール位置

消えたファイルや移動したファイルのタブは復元しません。ファイルの内容が短くなってカーソル位置がはみ出す場合は、ファイルの末尾に置きます。
