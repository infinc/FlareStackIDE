# Interpolate Variable

コードを打っている途中で、変数名・関数名・モジュール名の候補をカーソルの下に表示します。

## 使い方

1. このプラグインをインストールします
2. コードを打ち始めると（例: `absolute` という変数があるとき `a` を打つ）、カーソルの下に候補が出ます
3. **Tab** で一番上の候補を入れます（設定で **Enter** に変えられます）
4. **↑ / ↓** で候補を選び、**Tab** で入れます
5. **esc** で候補を閉じます

候補をクリックしても入れられます。

## 候補になるもの

- 開いているファイルに出てくる名前（変数・関数・クラスなど）
- プロジェクト内の同じ種類のファイル名（Python の `import` するモジュール名など）

Markdown やテキストファイルでは、日本語や英語の文章の補完をしないよう、候補を出しません。

## 設定

歯車メニューの「プラグイン」から Interpolate Variable の「設定」を押すと、補完するキーを **Tab** か **Enter** から選べます。
