# Code Folding

関数やブロックを折りたたんで隠すプラグインです。隠すのは表示だけで、保存される内容は変わりません。

## 使い方

| 操作 | 内容 |
|---|---|
| 行番号の右のマークをクリック | 折りたたみ・展開（Lines が必要） |
| 行末の ⋯ をクリック | 展開 |
| ⌥⌘← / ⌥⌘→ | カーソル位置を折りたたみ / 展開 |
| ⌥⇧⌘← / ⌥⇧⌘→ | すべて折りたたみ / すべて展開 |

折りたたんだ部分にカーソルが入ったり、その部分を編集したりすると、自動で展開します。折りたたみの状態はアプリを閉じるまで保持します。

## 判定の方法

| 対象 | 方法 |
|---|---|
| 一般のコード | コメントと文字列を除いた `{}` `[]` `()` |
| Python・YAML | インデント |
| HTML・XML | タグ |
| Markdown | 見出し |

40万文字を超えるファイルは対象外です。
