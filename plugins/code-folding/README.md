# Code Folding

関数やブロックを折りたたんで隠すプラグインです。隠すのは表示だけで、保存される内容は変わりません。

## 使い方

| 操作 | 内容 |
|---|---|
| 行番号の右のマークをクリック | 折りたたみ・展開（Lines が必要） |
| 行末の ⋯ をクリック | 展開 |
| ⌥⌘← / ⌥⌘→ | カーソル位置を折りたたみ / 展開 |
| ⌥⇧⌘← / ⌥⇧⌘→ | すべて折りたたみ / すべて展開 |

折りたたんだ部分にカーソルが入ったり、その部分を編集したりすると、自動で展開します。折りたたみの状態はアプリを閉じるまで保持します。

## 判定の方法

| 対象 | 方法 |
|---|---|
| 一般のコード | コメントと文字列を除いた `{}` `[]` `()` |
| Python・YAML | インデント |
| HTML・XML | タグ |
| Markdown | 見出し |

40万文字を超えるファイルは対象外です。

## 更新履歴

### v1.4

- プラグイン API 3（apiVersion 3）への対応
- 行の位置の計算を本体の LineIndex に統一し、大きなファイルでの処理を軽量化

### v1.3

- プラグイン API 2（apiVersion 2）への対応
- プラグインフィードのカテゴリ「表示」の追加
- ほかのプラグインとの連携に使う通知名を本体の共通定義に統一

### v1.2

- Lines プラグインを必要なプラグインとして指定（未インストールなら一緒にインストール）
- プラグイン API 1（apiVersion 1）への対応
- 配布ファイルのハッシュと署名による改ざんの確認に対応

### v1.1

- SQL・Lua の `--` コメントと Lua の `--[[ ]]` コメントに対応
- JavaScript / TypeScript の正規表現リテラル、Rust のライフタイム `'a` の中の括弧を無視するよう改善
- シェルスクリプトの `#` を、行頭か空白の後だけコメントとして扱うよう修正
- インデントで折りたたむ言語で、空行を挟んだブロックの範囲を改善
- Markdown の `~~~` や4つ以上の ``` のコードブロック内の `#` を見出しとして扱わないよう修正
