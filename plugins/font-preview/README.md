# Font Preview

フォントファイル（`.ttf`・`.otf`・`.ttc`・`.woff` など）を開くと、見本の文章・文字の一覧・全てのグリフを表示するプラグインです。フォントを Mac にインストールせずに確かめられます。

## 使い方

- 上のバーの欄に文字を入れると、見本をその文字で表示します。スライダーで見本の大きさを変えられます。
- `.ttc` などの複数のフォントが入ったファイルは、左のメニューでフォントを選びます。
- 日本語や欧文のアクセント記号は、フォントが対応しているときだけ表示します。
- 「Font Book で開く」で Font Book に渡し、インストールできます。

## 設定

- **見本の文字**: 最初に表示する見本の文章です。
