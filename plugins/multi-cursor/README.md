# Multi Cursor

同じ文字列を探して、まとめて変換するプラグインです。

## 使い方

1. 上のバーのリファクタリングボタンを押すと、編集画面の上に専用フィードが開きます
2. 検索欄に文字を入れ、範囲（現在開いているファイル / 全てのファイル）を選びます。ヒットした件数が表示され、編集画面では背景が黄色くなります
3. `<` `>` でヒットした場所へ移動します（別のファイルは開きます）
4. 変換後の文字列を入れて「リファクタリング」を押すと全て変換します。右下の通知の「元に戻す」で戻せます

背景の色はプラグインの設定で変えられます。全てのファイルの検索では、1MB を超えるファイルとバイナリは対象外です。
