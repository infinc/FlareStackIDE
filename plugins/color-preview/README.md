# Color Preview

色を作って値を確認するプラグインです。

## 使い方

上のバーの筆ペンボタンを押すと、編集画面の上に専用フィードが開きます。色の図・RGB のスライダー・16進数のどれからでも色を作れ、16進数・`rgb()`・`hsl()` の値をコピーできます。
