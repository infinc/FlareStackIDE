# Bookmarks

行に印を付けて、すぐに戻れるようにするプラグインです。

## 使い方

| 操作 | 内容 |
|---|---|
| 行番号をクリック | その行の印を切り替え（Lines が必要） |
| ⌥⌘B | カーソル行の印を切り替え |
| ⌥⌘↓ / ⌥⌘↑ | 次 / 前の印へ移動 |

左のアイコン列のしおりボタンで、プロジェクト内の印の一覧を開きます。行を押すとその場所へ移動します。

印はプロジェクトごとに保存され、行の追加や削除に合わせて動きます。行が消えると印も消えます。

Lines を入れていると行番号の左に青い点、Scroll Assistant を入れているとミニマップに青い帯を表示します。
