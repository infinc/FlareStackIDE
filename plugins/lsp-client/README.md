# LSP Client

Language Server Protocol（LSP）の言語サーバーとつないで、コードの意味を理解した機能を使えるようにするプラグインです。今は Python（`.py` / `.pyi` / `.pyw`）に対応しています。

## 準備

次のどれかの言語サーバーをインストールしてください（上から順に探します）。

| 言語サーバー | インストール |
|---|---|
| Pyright | `pip install pyright` または `npm install -g pyright` |
| basedpyright | `pip install basedpyright` |
| python-lsp-server | `pip install python-lsp-server` |

ログインシェル（zsh）の `PATH` から探すので、ターミナルで使えるコマンドならそのまま動きます。別のコマンドを使うときは、設定の「言語サーバーのコマンド」に書いてください（例: `/opt/homebrew/bin/pyright-langserver --stdio`）。

## できること

| 機能 | 操作 |
|---|---|
| 診断 | エラーと警告に波線を引きます |
| ホバー | 名前の上でマウスを1秒止めると、型や説明を表示します（診断があれば一緒に出します） |
| 定義へ移動 | F12 か ⌘クリック。別のファイルなら開きます |
| 参照を検索 | ⇧F12。一覧から選ぶとその場所へ移動します |
| 名前の変更 | F2。プロジェクト全体の該当箇所を書き換えます。通知の「元に戻す」で戻せます |
| 補完 | Interpolate Variable プラグインが入っていれば、言語サーバーの候補を先頭に出します |

どの操作もコマンドパレット（⌘⇧P）の「LSP: …」から実行でき、Shortcut プラグインでキーを割り当てることもできます。「LSP: 言語サーバーを再起動」でサーバーを起動し直せます。

言語サーバーはプロジェクトごとに1つ起動し、そのプロジェクトのウィンドウをすべて閉じると終了します。

## Code Scanner と一緒に使うとき

両方入れても競合しないようにしています。

- 波線・右上の数・問題フィード・ミニマップの印は Code Scanner がまとめて表示します（問題フィードには出元の `Pyright` などが付きます）
- 言語サーバーが動いているファイルでは、Code Scanner の外部ツールによる検査（`python3` の構文チェック）を止め、同じエラーが二重に出ないようにします。全角スペースやマージ競合の印など、Code Scanner だけが見つけるものは引き続き表示します
- ホバーのポップアップは1つにまとめ、言語サーバーの診断と型の情報を一緒に出します
- どちらかを外すと、残った方だけで元どおりに動きます
