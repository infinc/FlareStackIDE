# Comment Toggle

選んだ行をまとめてコメントにしたり、コメントを外したりするプラグインです。

## 使い方

- ⌘/ を押すと、選んだ行（選んでいなければカーソルの行）をコメントにします。もう一度押すと外します
- 選んだ行が全てコメントなら外し、1行でもコメントでない行があれば全てに付けます。空行はそのままです
- 記号はファイルの種類で変わります（`//`・`#`・`--`・`%`・`;`）。HTML・XML・Markdown は `<!-- -->`、CSS は `/* */` で囲みます
- コマンドパレットの「コメントの切り替え」からも使えます。1回の取り消し（⌘Z）で元に戻ります

## キーの変更

Shortcut プラグインを入れると、Shortcut の設定に「コメントの切り替え」が ⌘/ で追加されます。そこでキーを変えたり、項目を消してキーをなくしたりできます。
