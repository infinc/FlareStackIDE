# Env Editor

`.env` ファイルを表で表示して編集するプラグインです。値は初期状態で伏せ字になるので、画面共有中でも秘密の値を見せずに済みます。

## 対象のファイル

`.env`、`.env.local` などの `.env.` で始まるファイル、`production.env` などの `.env` で終わるファイル

## 使い方

- 表の列はキー・値・コメントです。値は `••••••••` で表示し、行の目のボタンで1行だけ、バーの「全て表示」で全てを表示します
- 表示した値・キー・コメントを編集すると、確定したときにファイルへ書き込みます
- 「行を追加」「行を削除」で変数を増やしたり消したりできます
- 同じキーが2回以上あると、キーを赤字で表示します
- 行を選んで ⌘C を押すと、その行の値をコピーします
- `export`・引用符・行末の `#` コメント・コメントだけの行・空行は、変えていない行ならそのまま残します

## 設定

- 開いたときに値を伏せ字にする（初期はオン）
