# Scroll Assistant

ファイル編集画面の右側に、開いているファイルのコードを小さく縦長に表示するプラグインです。

## 使い方

1. このプラグインをインストールします
2. カーソルを合わせると背景が少し白くなり、いま編集画面に表示している部分がさらに白くなります
3. 白い部分を上下にドラッグすると、編集画面がスクロールします。他の場所を押すと、その位置へ移動します

## Code Scanner との連携

Code Scanner をインストールしていると、エラーの行は背景が赤く、警告の行は背景が黄色く表示されます。右に開いた分割画面でも同じように表示されます。

ファイルを開いていないとき（File Tab Cleaner などでタブを全て閉じたときも）は表示しません。

Word Highlight を入れると、クリックした語がある行を水色で表示します。
