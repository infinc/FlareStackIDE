# Terminal Copy

内蔵ターミナルの文字を、ドラッグするだけでコピーできるプラグインです。

## 使い方

1. このプラグインをインストールします
2. ターミナル（Runner の実行フィードも含む）で、コピーしたい文字をドラッグして選択します
3. マウスを離すと、選んだ文字がそのままクリップボードにコピーされます

⌘C を押す必要はありません。選択は、ターミナルをクリックするかキーを入力すると消えます。
