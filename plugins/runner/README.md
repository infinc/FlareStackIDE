# Runner

プログラムを実行するプラグインです。

## 使い方

1. このプラグインをインストールします
2. 左のアイコン列のターミナルボタンの上に、実行ボタン（▶）が追加されます
3. 実行ボタン右上の小さな ⌄ を押し、「起動構成を編集」→「新規作成」で起動構成を作ります（テンプレートから選ぶか、テンプレートなしを選びます）
4. 実行ボタンを押すと、選んだ起動構成で実行し、下のフィードに結果を表示します

実行フィードを閉じている間にプログラムが終わると、右下に「実行が終了しました」と通知します。通知のボタンで実行フィードを開けます。

## 起動構成

| 項目 | 内容 |
|---|---|
| 名前 | メニューに表示する名前 |
| 作業ディレクトリ | 実行する場所。空ならプロジェクトのフォルダ。相対パスはプロジェクトのフォルダから |
| スクリプト | 実行するファイル（`main.py` など）、またはそのまま実行するコマンド |
| スクリプトパラメーター | スクリプトの後ろに付ける引数 |
| 環境変数 | 1 行に `KEY=VALUE`。`.env` ファイルより優先 |
| .env ファイルのパス | 読み込む環境変数のファイル。相対パスは作業ディレクトリから |

起動構成はプロジェクトごとに保存されます。初期状態では起動構成はありません。

## 対応しているファイル

`py` / `pyw`（python3）、`js` / `mjs` / `cjs`（node）、`ts` / `tsx` / `mts` / `cts`（tsx）、`rb`、`sh` / `bash` / `zsh`、`swift`、`go`、`php`、`pl`、`lua`、`java`、`c` / `cpp`（clang でビルドして実行）、`rs`（rustc でビルドして実行）。それ以外は実行可能ファイルならそのまま実行します。

スクリプトが空の起動構成は実行せず、通知を出します。

実行フィードの ■ で停止、↻ で再実行できます。
