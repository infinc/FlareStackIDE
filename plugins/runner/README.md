# Runner

プログラムを実行するプラグインです。

## 使い方

1. このプラグインをインストールします
2. 左のアイコン列のターミナルボタンの上に、実行ボタン（▶）が追加されます
3. 実行ボタン右上の小さな ⌄ を押し、「新しい起動構成…」で起動構成を作ります
4. 実行ボタンを押すと、選んだ起動構成で実行し、下のフィードに結果を表示します

## 起動構成

| 項目 | 内容 |
|---|---|
| 名前 | メニューに表示する名前 |
| 作業ディレクトリ | 実行する場所。空ならプロジェクトのフォルダ。相対パスはプロジェクトのフォルダから |
| スクリプト | 実行するファイル（`main.py` など）、またはそのまま実行するコマンド |

起動構成はプロジェクトごとに保存されます。初期状態では起動構成はありません。

## 対応しているファイル

`py`（python3）、`js` / `mjs` / `cjs`（node）、`ts`（tsx）、`rb`、`sh` / `bash` / `zsh`、`swift`、`go`、`php`、`pl`、`lua`、`java`、`c` / `cpp`（clang でビルドして実行）、`rs`（rustc でビルドして実行）。それ以外は実行可能ファイルならそのまま実行します。

実行フィードの ■ で停止、↻ で再実行できます。
