# Hex Viewer

テキストとして開けないファイル（バイナリ）を、16進数とASCII文字で表示するプラグインです。表示のみで、編集はできません。

## 使い方

1. このプラグインをインストールします
2. 実行ファイルやデータファイルなど、テキストではないファイルを開くと自動で16進数の表示になります

画像・動画・PDF は対象外です（Picture & Video Viewer・PDF Viewer が表示します）。

## 表示

| 列 | 内容 |
|---|---|
| 左 | 行の先頭のオフセット（16進数） |
| 中央 | 1行16バイトの値。`00` は薄く表示します |
| 右 | ASCII 文字。表示できない値は `·` |

## 操作

| 操作 | 内容 |
|---|---|
| クリック | そのバイトを選び、上のバーにオフセットと値を表示します |
| ← → ↑ ↓ | 選んだバイトを移動します |
| ⌘C | 選んだバイトの値をコピーします |
| オフセットへ移動 | 上のバーの欄に `0x1F` や `31` を入れて Enter |

大きなファイルでも、画面に見えている行だけを描くので軽く動きます。文字の大きさはエディタのフォントサイズに合わせます。
