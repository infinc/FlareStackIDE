# Remote SSH

SSH で接続できるサーバーのフォルダを手元に取得し、いつもと同じようにプロジェクトとして編集します。保存すると、変更したファイルを `rsync` でリモートに送り返します。

## 使い方

1. 左のアイコン列の 🌐（リモート (SSH)）→「SSH で接続…」を押します（コマンドパレットの「リモート:」からも使えます）
2. ホスト（`~/.ssh/config` の Host か `user@host`）と、リモートのフォルダを入力して「接続」を押します
3. フォルダを `~/Library/Application Support/FlareStackIDE/Remote/` に取得して、プロジェクトとして開きます
4. ファイルを保存すると、変更したファイルだけをリモートに送ります
5. 🌐 →「リモートのターミナルを開く」で、リモートのフォルダで `ssh` のターミナルを開きます
6. 🌐 →「リモートから取得」で、リモートの変更を取り込みます

## 準備

- 鍵（`ssh-agent` か `~/.ssh/config` の `IdentityFile`）でパスワードなしに接続できるホストだけに対応しています。パスワードは扱いません
- リモートにも `rsync` が必要です
- 接続は `ControlMaster` で使い回します（`~/.ssh/flarestack-*`、10分で閉じる）

## 制限

- 手元で消したファイルは、リモートでは消しません
- リモートの変更は自動では取り込みません。「リモートから取得」を押してください
- 言語サーバー（LSP Client）やコードの検査は、手元のコピーに対して動きます
- 取得しないフォルダ（既定: node_modules, .venv, venv, __pycache__, build, DerivedData など）は、プラグインの設定で変えられます
