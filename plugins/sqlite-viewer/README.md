# SQLite Viewer

SQLite のデータベースを表で表示するプラグインです。`.sqlite`・`.sqlite3`・`.db` などのファイルを開くと使えます（中身が SQLite のファイルだけ）。

## 使い方

- 上のバーの左でテーブルやビューを選ぶと、その中身を表示します。「構造」に切り替えると列の名前・型・主キーなどを表示します。
- SQL の欄に `SELECT` などを書いて Enter か「実行」で実行します。`;` で区切ると続けて実行し、最後の結果を表示します。
- 行を選んで ⌘C を押すと、列名と一緒にタブ区切りでコピーします。
- 長い値はマウスを重ねると全体を表示します。

## 設定

- **表示する行数の上限**: これより多い行は表示しません（初期値は 1000 行）。続きは `LIMIT` と `OFFSET` で表示できます。
- **書き込みを許可**: 初期はオフで、データベースを読み取り専用で開きます。オンにすると `INSERT`・`UPDATE`・`DELETE` なども実行できます。設定を変えたらファイルを開き直してください。
