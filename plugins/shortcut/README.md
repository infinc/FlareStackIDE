# Shortcut

好きなキーの組み合わせに、よく使う操作を割り当てるプラグインです。

## 使い方

1. このプラグインをインストールします
2. 歯車メニューの「プラグイン」から Shortcut の「設定」を押します
3. 「ショートカットを追加」を押します
4. キーの欄を押してから、割り当てたいキーの組み合わせを押します（⌘・⌃・⌥ のどれかを含めるか、F1〜F15。esc で取り消し）
5. 右のメニューから操作を選びます

ファイル編集画面でそのキーを押すと、選んだ操作が実行されます。ショートカットはいくつでも作れ、− ボタンで削除できます。

## 選べる操作

- **実行** — Runner プラグインの ▶ と同じく、選んでいる起動構成で実行します（Runner プラグインが必要です）
- **テーマ切り替え** — 歯車メニューの「テーマ」を上から順に切り替えます
- **プロジェクトを保存して終了** — すべてのファイルを保存して、初期画面に戻ります
