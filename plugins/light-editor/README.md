# Light Editer

ファイル1つだけを軽く編集するためのエディタです。

## 使い方

1. このプラグインをインストールします
2. Finder でファイルを右クリックし、「このアプリケーションで開く」から FlareStackIDE を選びます
3. 「プロジェクトとして保存しますか？」の画面で「Light Editerで開く」を押します

## できること

Light Editer にはディレクトリのフィードや中タブはありません。あるのは次の3つだけです。

- ファイルの編集
- 自動保存
- 左側の行数表示（Lines プラグインをインストールしているとき）

色・フォント・自動保存の間隔などは、通常のエディタの設定をそのまま使います。
