# Bracket Colorizer

コード内の括弧 `()` `[]` `{}` を深さごとに色分けするプラグインです。

## 使い方

インストールすると、開いているファイルの括弧に深さ1・2・3の色が順に付きます。4段目からは同じ順番で色を繰り返します。

カーソルを括弧の前か後ろに置くと、その括弧と対応する括弧の背景を強調します。対応する括弧がない括弧は赤で表示します。

文字列（`"..."` `'...'` `` `...` ``）とコメント（`//` `/* */` `#` `--` など）の中の括弧は数えません。右に開いた分割画面でも使えます。

## Code Colors との関係

Code Colors の色付けの後に括弧の色だけを上書きするので、Code Colors と一緒に使っても他の文字の色は変わりません。

## 設定

- **深さ1〜3の色**
- **対応する括弧の背景色**
- **対応のない括弧を赤くする**

40万文字を超えるファイルでは色を付けません。
