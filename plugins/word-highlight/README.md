# Word Highlight

クリックした語と同じ語を強調するプラグインです。

## 使い方

変数などを左クリックすると、そのファイル内の同じ語の背景を少し強調します。Scroll Assistant があれば、その語がある行を水色で表示します。背景の色はプラグインの設定で変えられます。
